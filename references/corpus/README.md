# The reference corpus

Everything in this directory is derived from the LaTeX sources of **46 papers**
from three groups: Tsinghua **MARS**, **Wenzhao Zheng**'s group, and **Megvii**.
They were chosen because their figures and their experiment sections are what
this suite is trying to be able to produce.

| | |
|---|---|
| Papers with complete arXiv sources | 46 (45 with enough prose to measure) |
| Venues | CVPR, ICCV, ECCV/LNCS, NeurIPS, ICLR, AAAI, ICRA/IROS, ACM MM, IEEE journals |
| Figure environments | 289 |
| Table environments | 300 |
| Figure PDFs analysed | 349 (in the CVPR-Figure corpus report) |
| Prose measured | ~200k words |

`profile.json` is the machine-readable summary. It is what
`scripts/audit_paper.py` compares a draft against, and it is regenerated by
`scripts/build_profile.py` with the same reader the auditor uses — so the
profile and the audit are always measuring the same quantity.

**The sources are not in this repository.** They are other people's papers.
What ships is the summary and the method.

## How to read a percentile here

A percentile is a description of what published work does, not a rule. Two
ways to misuse it:

- Treating the median as a target. Half the corpus is on each side of it.
- Treating an outlier as a defect. A paper can sit at the 95th percentile for
  a good reason; the auditor's job is to make you say what the reason is.

The one place the numbers *are* close to rules is the `error` tier of the prose
audit, which fires only where **no paper in the corpus** does the thing. That
tier was validated by running the auditor over all 45 papers: it reports zero
errors on every one of them, and 11 on a deliberately AI-written draft of the
same length.
